# Clock_Widget
Ovelay Clock
<img width="1367" height="703" alt="image" src="https://github.com/user-attachments/assets/e96926ea-0c43-432d-b5d4-06671fd1939d" />


전체 화면 또는 전체 창 모드로 게임을 플레이할 때, 주 모니터에서 현실 시간을 확인할 수 있도록 만든 시계 위젯입니다.

MSI Afterburner 같은 프로그램도 있지만, 설치 과정이 번거로울 수 있어 간단한 대용으로 사용하고자 제작했습니다.

무설치 버전이므로 사용 방법은 간단합니다. 
압축을 푼 뒤 「RunClockWidget.bat」 파일을 실행하시면 됩니다.
